Caveman Cloud separates **Connectors** and **Secrets** into two distinct primitives because they solve different security problems.

## Connectors

Connectors hold team-authenticated SaaS and remote MCP integrations (such as GitHub, Slack, Linear, Jira, or internal MCP servers):

- **Pinned tool catalogs:** Administrators review and accept a Connector's exposed tools before deployments build against them. `cvm connect diff` highlights any upstream tool schema drift.
- **Effect classification:** Every tool carries an explicit effect label (`read`, `write`, or `external`), and deployments receive least-privilege grants capped by effect ceiling and environment (`production`, `preview`, `development`).
- **Relay-enforced auth:** Underlying OAuth tokens remain in the platform relay and never enter a Sandbox.

```bash
cvm connect add github
cvm connect accept github --yes
cvm connect grant github --to pr-reviewer --ceiling read
```

```ts
import { Caveman } from "@caveman-ai/sdk";

const cv = new Caveman();
const connectors = await cv.connectors.list();
await cv.connectors.grant("github", { deployment: "pr-reviewer", ceiling: "read" });
```

## Secrets

Secrets hold raw KMS-encrypted credentials (`STRIPE_API_KEY`, `NPM_TOKEN`, `DATABASE_URL`) scoped to an organization, repository, agent, or environment:

- **Write-only by design:** Once written, secret values are never returned back through the API, SDK, CLI, or console. List endpoints return metadata only.
- **Per-command boundary injection:** Secrets are injected only into authorized commands at execution time and are never written onto VM disks or exposed to model context.
- **Preview isolation:** Pull-request preview deployments never receive production secrets unless a secret explicitly opts into preview access.

```ts
import { Caveman } from "@caveman-ai/sdk";

const cv = new Caveman();

// Write a secret (value is encrypted server-side and never returned)
await cv.secrets.set({
  name: "STRIPE_API_KEY",
  value: process.env.STRIPE_API_KEY!,
  environment: "production",
});

// List returns names and scope metadata only
const list = await cv.secrets.list();
```
