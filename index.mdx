Caveman Cloud is a Cloud for AI. One scoped API key and one prepaid Credits balance power both standalone infrastructure primitives and a full Managed Agents platform.

Start with any single primitive, or compose all ten together. Use the unified Inference Gateway with zero SDK changes, rent Firecracker Sandboxes and versioned Drives from your existing backend, or deploy autonomous agents with an `instructions.md` + `agent.json` folder or `@caveman-ai/agent`.

## The ten primitives

Every capability is available independently over REST, SSE, WebSockets, the unified `Caveman` SDK (`@caveman-ai/sdk`, `caveman-sdk`, `github.com/caveman-ai/sdk-go`), the `cvm` CLI, and scoped MCP servers.

| Layer | Primitive | What it does |
| --- | --- | --- |
| Inference | [Models and Gateway](/platform/inference-and-models) | Multi-provider OpenAI and Anthropic gateway with smart routing, failover, ZDR, caching, CCR, and Caveman models (`auto`, `trim-1`, `compact-1`). |
| Managed Agents | [Agents](/platform/managed-agents) | Versioned agent builds (`instructions.md` + `agent.json` or `@caveman-ai/agent`), immutable Deployments, rollbacks, Skills, and Triggers. |
| Managed Agents | [Sessions](/platform/sessions) | Durable execution timelines with append-only logs, automatic step durability, human approvals, time-travel fork, and one-click eval promotion. |
| Managed Agents | [Sandboxes](/platform/sandboxes) | On-demand Firecracker microVMs (`code` and `linux`), $0-idle auto-pause, Exec/PTY, Environments, Snapshots, and Port URLs. |
| State and Access | [Drives](/platform/drives) | Durable, versioned long-term filesystems with zero-VM read/edit/grep/diff, Sandbox and WebDAV mounts, human-reviewable Changesets, and session undo. |
| State and Access | [Connectors](/platform/connectors-and-secrets#connectors) | Team-authenticated SaaS and MCP integrations with pinned tool catalogs, effect labels, and per-deployment grants. |
| State and Access | [Secrets](/platform/connectors-and-secrets#secrets) | Write-only KMS-encrypted credentials scoped by org, repo, agent, or environment and injected per command at the execution boundary. |
| Multi-Agent Apps | [Rooms](/platform/rooms-and-apps#rooms) | Shared multi-agent and human threads with atomic task leases, DAG dependencies, taint propagation, watchers, and cross-session cost rollups. |
| Multi-Agent Apps | [Apps](/platform/rooms-and-apps#apps) | Isolated-origin interactive UIs backed by Drives or Sandbox ports using short-lived `capp_` capability bridge tokens. |
| Quality and Control | [Evals](/guides/evals) and [Governance](/governance/overview) | Datasets from live Sessions, deterministic and computer verifiers, CI deploy gates, Inbox approvals, Credits, and audit logs. |

## Savings evidence

Caveman Cloud reports three kinds of numbers and keeps them separate:

- **Measured spend** records observed usage and its pricing basis.
- **Inferred savings** describe an estimate or counterfactual, not a guaranteed invoice reduction.
- **Verified savings** require a supported accounting method and qualifying evidence. They stay zero when that evidence is absent.

See [Savings Evidence](/concepts/savings-evidence), [Optimization Catalog](/concepts/optimizations), and [Reporting Savings](/solutions/reporting-savings).
