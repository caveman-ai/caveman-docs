## 1. Call any model (2 minutes, zero SDK)

Point an existing OpenAI or Anthropic client at `https://gateway.caveman.so/v1` and pass a `maker/model` slug. Your connected provider keys pay first with no fee; Caveman Credits cover any remaining providers at list price.

```bash
export CAVEMAN_API_KEY="cave_live_..."
```

<CodeGroup>

```ts TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.CAVEMAN_API_KEY,
  baseURL: "https://gateway.caveman.so/v1",
});

const response = await client.chat.completions.create({
  model: "anthropic/claude-sonnet-4-6",
  messages: [{ role: "user", content: "Summarize our SLA in two bullets." }],
});

console.log(response.choices[0].message.content);
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["CAVEMAN_API_KEY"],
    base_url="https://gateway.caveman.so/v1",
)

response = client.chat.completions.create(
    model="anthropic/claude-sonnet-4-6",
    messages=[{"role": "user", "content": "Summarize our SLA in two bullets."}],
)

print(response.choices[0].message.content)
```

```bash curl
curl https://gateway.caveman.so/v1/chat/completions \
  -H "authorization: Bearer ${CAVEMAN_API_KEY}" \
  -H "content-type: application/json" \
  -d '{"model":"anthropic/claude-sonnet-4-6","messages":[{"role":"user","content":"Hello, Caveman"}]}'
```

</CodeGroup>

## 2. Use Sandboxes, Drives, and Secrets with the unified SDK

Install `@caveman-ai/sdk` (TypeScript), `caveman-sdk` (Python), or `github.com/caveman-ai/sdk-go` (Go) to compose every primitive from one `Caveman` client.

<CodeGroup>

```ts TypeScript
import { Caveman } from "@caveman-ai/sdk";

const cv = new Caveman(); // reads CAVEMAN_API_KEY

// Search a versioned Drive without booting a VM
const hits = await cv.drives.drive("knowledge").grep({ pattern: "refund" });

// Run isolated code in a $0-idle Firecracker Sandbox
const sb = await cv.sandboxes.create({ name: "scratch", size: "2cpu-4gb" });
const out = await sb.exec(["python3", "-c", "print(2 + 2)"]);
console.log(out.stdout, hits.matches.length);
await sb.delete();
```

```python Python
from caveman_cloud import Caveman

cv = Caveman()  # reads CAVEMAN_API_KEY
hits = cv.drives.drive("knowledge").grep({"pattern": "refund"})
models = cv.inference.models()
print(len(models), len(hits["matches"]))
```

</CodeGroup>

## 3. Deploy a Managed Agent

Author an agent declaratively with an `AGENT.md` folder (or in TypeScript with `@caveman-ai/agent`), test locally with `cvm agent dev`, and deploy an immutable revision with `cvm deploy`.

```bash
npm install -g @caveman-ai/cloud
cvm login
cvm agent init pr-reviewer ./pr-reviewer
cvm deploy ./pr-reviewer --name pr-reviewer --budget 2
cvm run pr-reviewer "Review the latest changes on main"
```
