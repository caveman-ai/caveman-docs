`caveman-browse` is a local MCP server that drives Chrome and gives the agent a compressed view of the page instead of the raw accessibility tree. On a 200-row operations table, a focused snapshot came to 121 tokens against 15,704 for the Playwright ARIA snapshot of the same page.

## Register it

```bash
caveman mcp install claude --server caveman-browse
```

That writes the registration into the agent's config and a marker recording that caveman owns it. With no agent named it installs for every known agent on `PATH`. `caveman mcp uninstall --server caveman-browse` removes both again.

The binary arrives with the rest:

```bash
caveman setup --install
```

```text
✓ caveman-browse  …/.caveman/bin/caveman-browse
    powers: browse + agent-side compressed browsing MCP tools — wrap auto-registers once present
```

One line of a real `caveman setup` run, path shortened. A default `caveman wrap` registers it on its own once the binary is present and Chrome resolves.

To register it by hand, the server is the binary with no arguments. `caveman mcp install` writes the absolute path it resolved, so do the same:

```json
{
  "mcpServers": {
    "caveman-browse": { "command": "/Users/you/.caveman/bin/caveman-browse" }
  }
}
```

## The four tools

| Tool | Input | What it does |
|---|---|---|
| `browser_snapshot` | `url`, `wait`, `query` | Navigates if `url` is given and returns a compact accessibility tree. `query` keeps the nodes that match the task and their ancestors |
| `browser_act` | `action`, `uid`, `text`, `option` | Runs `click`, `type`, `select`, `scroll` or `wait` against a UID from the latest snapshot |
| `browser_eval` | `expression` | Runs JavaScript in the current page |
| `browser_recover` | `recovery_handle`, `query` | Returns the exact raw accessibility bytes behind a snapshot handle |

`action` is the only required field on `browser_act`; `recovery_handle` and `expression` are required on their tools. `wait` is milliseconds, capped at 30,000. `url` accepts `http`, `https`, `about:blank` and a bounded `data:text/html`, and rejects local files and privileged schemes.

A snapshot payload carries `uids`, `recovery_handle`, `tokens_before`, `view_tokens`, `tokens_after`, `ratio` and `basis`. `tokens_after` counts the exact result the agent sees; `view_tokens` isolates what the compact tree alone costs.

## The compact view

The compact tree is one line per node, `[uid] role "name"`. A UID is spent only on a node the agent can act on, or on a custom role the compressor does not recognise, so a page of static text does not pay for identifiers nobody will use.

An action reports `settled:false` until a later focused snapshot proves the new state. Acting and then believing the action worked is the failure that convention exists to prevent.

## The numbers

Measured 2026-08-10 with Chrome 151.0.7922.108, `@playwright/test` pinned at 1.56.1, and the offline `o200k_base` counter. Five independent Chrome runs, median with the range in brackets. The corpus is `browse/testdata/order_dashboard.html`, a 200-row operations table with one order to act on.

| Representation | Tokens | Against raw | Against Playwright |
|---|---:|---:|---:|
| Raw `Accessibility.getFullAXTree` JSON | 398,494 [398,493 to 398,497] | | |
| Playwright `ariaSnapshot()` | 15,704 | 96.06% less | |
| Caveman full result | 13,368 [13,367 to 13,368] | 96.65% less | 14.88% less |
| Caveman focused result, query `ORD-0173` | 121 [121 to 122] | 99.97% less | 99.23% less, 129.8 times smaller |

The Playwright baseline is its ARIA text alone: no MCP envelope, no action references, no recovery handle, no accounting. That asymmetry favours Playwright, and the numbers are quoted with it in place.

The same measurement on `browse/testdata/agent_checkout.html`, a small checkout form, goes the other way:

| Representation | Tokens | Against raw | Against Playwright |
|---|---:|---:|---:|
| Raw `Accessibility.getFullAXTree` JSON | 4,186 [4,183 to 4,188] | | |
| Playwright `ariaSnapshot()` | 67 | 98.40% less | |
| Caveman full result | 157 [156 to 159] | 96.25% less | 2.34 times larger |
| Caveman focused result, query `Email Plan Save order` | 111 [110 to 113] | 97.35% less | 1.66 times larger |

<Note tone="honest" title="The small-page row is a loss and it stays published">
On a tiny page the recovery handle, the exact counters, the basis field and the action UIDs cost more than bare ARIA text. Caveman is 2.34 times larger than Playwright there. It still cuts 97.35 percent against the raw tree and carries enough state to type, select, click, verify and recover the bytes, but no universal snapshot-only win is claimed. Both tables are `inferred` token counts for one snapshot, never provider usage or billing. [Numbers and limits](/docs/counting#inferred) defines the word.
</Note>

The full method, the corpus, the provenance hashes and the reproduction commands are in `browse/BENCHMARK.md` in the repository. The four-tool MCP catalog itself is separately locked at 287 tokens.

## Drive it from the shell

The same binary has a direct CLI, which is useful for checking a page without an agent in the loop.

```text
usage: caveman browse <url> [query]
       caveman browse act <uid> click|type|select|scroll [text]
       caveman browse recover <handle> [query]
       caveman browse eval <expression>
       caveman browse close
```

```bash
caveman browse http://127.0.0.1:3000 "save settings"
caveman browse close
```

Direct commands share one detached, isolated Chrome until `close`. The first use creates the profile and recovery directories. `CAVEMAN_BROWSE_CHROME` points at a specific Chrome, and `CAVEMAN_BROWSE_BIN` at a specific `caveman-browse`.

## Limits

Phase 1 covers same-origin pages with predictable controls. Out-of-process iframes, dialogs, downloads and actionability on an arbitrary site are deferred, so treat the benchmark as applying to this corpus and this toolchain.

Query-focused disclosure is the default on a large page, and a full snapshot is available when the task intent is unknown. Recovery is backed by the same store as the rest of caveman, so `browser_recover` returns the byte-exact original accessibility payload for any snapshot handle.

The binary is BSL 1.1. [Licensing](/docs/licensing) has the boundary.
