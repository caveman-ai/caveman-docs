`@caveman-ai/agent` is a TypeScript runtime for tool-using agents: you declare the tools, the context, the output contract and the budget, and it owns the loop. Every run returns a receipt that itemises what it spent, per model call, per tool and per subagent.

Want to cut the cost of an agent you already run in a terminal? Use [Wrap an agent](/docs/proxy/wrap).

```ts
import { agent, auto, run } from "@caveman-ai/agent";

const reviewer = agent({
  id: "reviewer",
  instructions: "Review the change. Name the root cause, not the symptom.",
  model: auto(),
});

const result = await run(reviewer, "Why does the parser drop trailing commas?");
```

Nine lines and one provider key. `auto()` resolves a model from `CAVE_MODEL`, then `.caveman/provider.json`, then the first provider credential in the environment, in that fixed order. It never classifies a task and never routes on quality.

## What a run returns

`RunResult` carries the answer, the ledger and the label for how the run reached the provider.

| Field | What it holds |
|---|---|
| `text` | The final assistant message. |
| `output` | That message parsed against the declared [output schema](/docs/agent-sdk/define#output-that-arrives-typed), typed from the schema. Absent when no schema is declared. |
| `receipt` | This run's `RunReceipt`: every call, every tool, every subagent's own receipt. |
| `mode` | `observe-only` when any call went straight to the provider, `optimized` when every call in the run and its subagents went through the local Caveman gateway. |
| `stopReason` | `complete`, or why the runtime stopped between calls: `budget_exhausted`, `deadline`, `loop_detected`, `no_progress`, `wallet_revoked`, `call_budget_exhausted`. |

The receipt from a two-call run against `@caveman-ai/agent/testing` at source 0.2.0, trimmed to one call, with the empty `tranches` and `breakers` arrays and `released` removed:

```json
{
  "schema": "caveman.agent.run-receipt.v1",
  "runId": "3df12c37-…",
  "agentId": "support-desk",
  "basis": "estimated_list_price_subtotal",
  "claimBasis": "inferred",
  "stopReason": "complete",
  "denomination": "usd",
  "max": 0.05,
  "spent": 0.0043948,
  "capBreached": false,
  "overspent": 0,
  "totalEstimatedUsd": 0.0043948,
  "totalTokens": 5734,
  "unpriced": false,
  "calls": [
    {
      "provider": "anthropic",
      "model": "claude-haiku-4-5",
      "inputTokens": 1260,
      "outputTokens": 38,
      "cacheReadTokens": 1024,
      "cacheWriteTokens": 1024,
      "reasoningTokens": 0,
      "estimatedUsd": 0.0028324,
      "unpriced": false,
      "usageBasis": "provider_reported"
    }
  ],
  "tools": [{ "name": "lookup_order", "calls": 1, "errors": 0 }],
  "subagents": [],
  "compactions": []
}
```

`runId` varies per run and is shortened here. Token counts come from the provider's own usage report, which is what `usageBasis` records. Every money figure is a public-catalog list price subtotal, labelled `inferred` on the receipt itself. [Numbers and limits](/docs/counting) defines that word.

<Note tone="honest" title="The receipt prices calls, it does not read your bill">
`estimatedUsd` multiplies provider-reported tokens by the public catalog price for that model. A model the catalog cannot price sets `unpriced: true` and contributes zero, which is why the flag exists: read it before reading the total. Under a USD budget an unpriced model fails the run before the first call rather than spending against a cap nothing can meter.
</Note>

## An agent as a directory

`loadAgentDir()` composes a directory into one ordinary `agent()` call, so prose lives in Markdown and tools live one per file.

```text
my-agent/
  instructions.md            required, the standing prose
  agent.ts                   required, default-exports { model, budget?, breakers?, context? }
  tools/lookup_order.ts      one tool() per file, filename equals tool name
  subagents/reviewer/        the same shape again, one level down
  .agents/skills/<name>/SKILL.md
```

```ts
import { loadAgentDir, run } from "@caveman-ai/agent";

const definition = await loadAgentDir(import.meta.dirname);
const result = await run(definition, ticket, { rootDir: import.meta.dirname });
```

A directory-loaded run defaults `printReceipt` on and writes the receipt JSON under `rootDir/.caveman/runs/`. Skill descriptions enter the cached prefix; skill bodies stay on disk until the model loads one. [Define an agent](/docs/agent-sdk/define#load-an-agent-directory) covers the rules the loader enforces.
