## Choose the right interface

Use the root package to define and run an agent. Use `/serve` for a Node server, `/serve-handler` when your host owns HTTP, `/durable` for storage, and `/execution-backend` for remote tools. `@caveman-ai/react` is the client view; it does not run the agent.

Adapters declare their own capabilities. Package presence, a source declaration, and a candidate test report do not establish live-provider certification or locked compiler support.

Current source is Apache-2.0. Installed older releases retain their own shipped licence.
