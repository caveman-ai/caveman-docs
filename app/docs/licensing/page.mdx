From Caveman 3.0.0, everything in the caveman repository is licensed under the Apache License, Version 2.0. That is the skill, the CLI, both client SDKs, the middleware, the browser extension, and the whole local runtime: the engine, the proxy, the rewriter, `caveman-browse`, the MCP server, `caveman-shrink`, cavemem and the shared Go platform. There is no longer a split by directory. The first releases under these terms are Caveman 3.0.0, the runtime binaries at `bin-v2.0.0` and the CLI at 2.0.0.

The [Agent SDK](/docs/agent-sdk) lives in its own repository, `caveman-ai/agent-sdk`, and is also Apache-2.0. The standalone `caveman-browse` repository is moving to Apache-2.0 as well. Caveman Cloud, the hosted service, is separate commercial software; its source is not in these repositories and none of this covers it.

`LICENSING.md` in the product repository is the source of truth. If it and this page ever disagree, it wins.

## What Apache-2.0 lets you do

In plain words, with no payment and no agreement to sign, you may:

- use Caveman for any purpose, including at work and in production
- change it, fork it, and keep your changes private if you want
- ship it inside your own product, free or paid, open or closed
- run it as a hosted or managed service for other people
- rely on a patent licence from everyone who contributed code, covering their contributions

In return, when you pass Caveman or a modified copy on to someone else:

- include a copy of the licence
- keep the copyright notices and the `NOTICE` file
- say in the files you changed that you changed them

Two limits come with it. The licence gives no rights to the Caveman name or logos (see [Trademarks](#trademarks)). And if you sue anyone claiming Caveman infringes your patent, the patent licence you received ends. The code comes with no warranty.

## The files

```text
LICENSE       the Apache License 2.0, verbatim
NOTICE        the copyright line and the third-party attributions
LICENSE-MIT   the MIT text that covered parts of the repository before 3.0.0
LICENSING.md  the summary, which wins over any other one including this page
```

Every package or module that ships its own `LICENSE` (the npm and PyPI packages, the npm launchers, the Go modules) carries an identical copy of the root one. Copyright is held by Julius Brussee.

## Earlier releases

A release keeps the licence it shipped with. Anything published before 3.0.0 stays under its original terms, and the Apache licence applies to 3.0.0 and later. Before 3.0.0 the repository was split:

- The skill and everything you adopt it with (the CLI, the SDKs, the middleware, the wire contracts, the provider catalog, the extension shell and the cavemem clients) were MIT.
- The compression engine and the Go binaries built on it (`engine/`, `proxy/`, `rewriter/`, `browse/`, `mcp/`, `shrink/`, the cavemem Go core, `shared/platform/`, and the extension's bundled `engine.wasm`) were Business Source License 1.1.

If you are on an older release and want the Apache terms, upgrade to 3.0.0 or later. The `@caveman-ai/agent` 0.1.0 package on npm was published from the caveman repository before the Agent SDK moved out, and it is MIT. Check the licence file shipped with whatever release you install.

## Contributions and third-party code

Contributions are inbound equals outbound: you license your change under Apache-2.0, the same terms as the rest of the repository. Commits carry a DCO sign-off. Code that outside contributors wrote under MIT before 3.0.0 stays available under MIT too, which is why `LICENSE-MIT` is kept and referenced from `NOTICE`.

`engine/pixel/` is a Go port of [pxpipe](https://github.com/teamchong/pxpipe) (MIT) with glyph atlases derived from Spleen 5x8 (BSD-2-Clause) and GNU Unifont (OFL-1.1 or GPLv2 with the font-embedding exception). The upstream notices travel with that source in `engine/pixel/NOTICE`. `browse/` links MIT-licensed chromedp modules; see `browse/NOTICE`. The runtime binaries ship the licence texts of the Go modules they link as `THIRD_PARTY_GO_LICENSES.tar.gz` with every release.
