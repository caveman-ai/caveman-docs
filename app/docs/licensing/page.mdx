Caveman ships under a split licence. The skill and everything you adopt it with are MIT, the compression engine and the Go binaries that embed it are BSL 1.1, and the Agent SDK is a separate repository under Apache-2.0. Which licence applies is decided by the path a file lives in, and `LICENSING.md` in the product repository is the source of truth.

Three files carry the text:

```text
LICENSE       MIT, with a scope note pointing engine-linked directories at LICENSE.BSL
LICENSE.BSL   Business Source License 1.1 for engine-linked code
LICENSING.md  the per-directory table, which wins over any summary including this one
```

## Path by path

| Path | Licence | What you may do |
|---|---|---|
| `skills/` | MIT | Anything, including shipping it inside a commercial product. |
| `packages/cli/` | MIT | Anything. It launches the BSL binaries but contains no engine code. |
| `packages/sdk/typescript/`, `packages/sdk/python/` | MIT | Anything. Thin clients. |
| `packages/agent/`, `packages/create-caveman-agent/` | MIT | Anything. Agent runtime, build compiler and initializer. |
| `packages/subagent-tax/` | MIT | Anything. Local measurement tool, no provider call. |
| `packages/shared/contracts/` | MIT | Anything. Public wire schemas. |
| `shared/provider-catalog/` | MIT | Anything. Model and price metadata. |
| `mem/js/`, `mem/py/` | MIT | Anything. Thin cavemem clients. |
| `evals/` | MIT | Anything. The skill's own benchmark harness. |
| `extension/` | MIT shell | The manifest, popup, content scripts and UI are MIT. The bundled `engine.wasm` is BSL 1.1, so any artifact that embeds it carries BSL terms for that combined work. |
| `engine/` | BSL 1.1 | Read it, fork it, run it for your own traffic including in production. |
| `proxy/` | BSL 1.1 | Same. Standalone gateway and provider adapters. |
| `rewriter/` | BSL 1.1 | Same. Reflection rewriter and recovery gates. |
| `browse/`, `mcp/`, `shrink/` | BSL 1.1 | Same. Go binaries that embed the engine. |
| `mem/` Go core | BSL 1.1 | Same. The clients under it stay MIT. |
| `shared/platform/` | BSL 1.1 | Same. Statically linked into the BSL binaries. |

A new module that imports, links, embeds or ships as part of the engine-linked runtime is BSL 1.1 by default, unless a later decision classifies it as an MIT adoption surface.

The [Agent SDK](/docs/agent-sdk) lives in its own repository, `caveman-ai/agent-sdk`, and its current source is Apache-2.0. The same package name exists in both places: `packages/agent/` in `JuliusBrussee/caveman` is MIT and is what the published `@caveman-ai/agent` 0.1.0 on npm ships from, while `packages/agent/` in `caveman-ai/agent-sdk` is Apache-2.0 at 0.2.0 and is where the work continues. Check the licence shipped with the release you install.

## The additional use grant, in plain words

BSL 1.1 is source-available rather than open source until its change date. The grant attached to this one permits, with no payment and no agreement:

- internal evaluation
- local development
- CI testing
- integration with your own systems
- self-hosted use for your own first-party traffic, production included

It does not permit offering the licensed work, or its functionality, to third parties as a hosted, managed or embedded service. That is the boundary, and crossing it needs a commercial licence from Julius Brussee. Named commercial and OEM partners can receive a separate signed carve-out for the specific hosted or embedded use that agreement covers.

The practical test is who the traffic belongs to. Running the proxy for your own company's agents is covered. Running it as a product other companies send their traffic to is not.

## Change date

Each BSL version converts to the Apache License, Version 2.0 on the earlier of two dates: `2030-06-21`, or the fourth anniversary of that version's first public distribution under BSL. Whichever comes first applies, so a version shipped today converts four years from today rather than waiting for 2030.

## Contributions and third-party code

MIT areas are inbound equals outbound MIT. BSL areas require a DCO sign-off and a relicence grant to Julius Brussee, so that commercial and OEM licences can include community contributions.

`engine/pixel/` is a Go port of [pxpipe](https://github.com/teamchong/pxpipe) (MIT) with glyph atlases derived from Spleen 5x8 (BSD-2-Clause) and GNU Unifont (OFL-1.1 or GPLv2 with the font-embedding exception). BSL 1.1 applies to the combined work, and the upstream notices travel with that source in `engine/pixel/NOTICE`. `browse/` vendors MIT-licensed chromedp modules; see `browse/NOTICE`.
