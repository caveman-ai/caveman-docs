An agent pays for every token it writes and every token it reads. Caveman shrinks both, on your machine, with no account. A rule file cuts the filler out of what the agent says, and a local proxy compresses the logs, JSON, diffs and tool output it reads, keeping the original bytes on disk so the agent can ask for them back.

## Install

The skill, for any of the agents in [Supported agents](/docs/skill/profiles):

```bash
npx skills add JuliusBrussee/caveman -g
```

The proxy, which needs the CLI and the signed binaries:

```bash
npm install -g @caveman-ai/cli && caveman setup --install
caveman claude        # or codex · gemini · aider · kilo · qwen · opencode · hermes · openclaw · pi
```

They stack, and each works without the other. [Quickstart](/docs/quickstart) installs the skill; [Add the local tools](/docs/quickstart/cli) installs the rest.

The same question answered twice, with and without the skill, is on [The skill](/docs/skill#what-it-changes): 69 tokens against 19, same diagnosis and same fix. Code, commands, file paths and exact error messages are copied through untouched, and [what it leaves alone](/docs/skill#what-it-leaves-alone) is the list.

## What it saves

| Who measured | What they found |
|---|---|
| [Adobe Research](https://arxiv.org/abs/2606.24083) | The CAVEWOMAN paper measured caveman-style output across eight models and five datasets and found it cut realised cost 1.4 to 2.4 times per model, up to 3 times. |
| [JetBrains](https://blog.jetbrains.com/ai/2026/07/speak-to-ai-agents-like-cavemen-tosave-tokens/) | 86 real coding tasks as a paired A/B with the skill alone: 8.5 percent fewer output tokens with no detectable quality change, sign test p = 0.82. |
| This repo's own runs | The committed skill eval and the pinned wrap benchmark, with their scopes and their one regression, are in [Published numbers](/docs/counting#published-numbers). |

Every figure a local tool prints for you is `inferred`, a per-run estimate from an offline token counter. [Numbers and limits](/docs/counting) defines that word and lists what caveman refuses to claim.

## How the parts fit

<StackDiagram />

The [skill](/docs/skill) is text your agent already reads, so it costs nothing to run and shortens what the agent writes. The [proxy](/docs/proxy) sits on loopback, holds your key, and shrinks eligible context on the way to the provider. [cavemem](/docs/memory) stores context once and recalls the part a question needs, so you stop resending it. [Caveman Cloud](/docs/cloud) is the managed plane across the network boundary, where a fleet's numbers can be compared against a bill.
