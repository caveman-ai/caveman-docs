`caveman-sdk` is a Python client for a Caveman service: it makes provider calls through that service and sends payloads to its compression endpoint, then returns the reply as dataclasses. It imports as `caveman_cloud`, uses only the standard library, and needs Python 3.13 or newer. This page documents published version 1.1.0.

Want tool results compressed inside LangChain or another Python framework, with no new code? Use [LangChain and Python](/docs/sdk/middleware/python).

## Install

```bash
pip install caveman-sdk
```

<Note tone="warning" title="Two names, and the short one is not ours">
The distribution is `caveman-sdk` and the import is `caveman_cloud`. The bare `caveman` package on PyPI belongs to someone else.
</Note>

## Configure

Every call goes to the address in `base_url`. The `/sdk/v1/*` routes that `compress()`, `context` and `runtime_policy` use are served by a Caveman service; the local proxy on 127.0.0.1:8787 serves the provider routes and the middleware runtime, not those.

```bash
export CAVE_BASE_URL="https://your-caveman-service.example"
export CAVE_API_KEY="your-service-key"
export OPENAI_API_KEY="your-provider-key"
```

`agent` is a label you choose. It travels as `x-cave-agent` so the service can group requests by which application made them.

## The smallest complete program

```python
import os
from caveman_cloud import Cave

cave = Cave(
    api_key=os.environ["CAVE_API_KEY"],
    base_url=os.environ["CAVE_BASE_URL"],
    agent="support-agent",
)

answer = cave.openai(upstream_key=os.environ["OPENAI_API_KEY"]).responses.create(
    {"model": "gpt-5.5", "input": "Explain what a retry loop is in one sentence."}
)
print(answer)

log = "\n".join(f"2026-09-16T10:00:00Z INFO worker={i} health check passed" for i in range(400))
report = cave.compress(log, content_type="log")

print(report.content_type, report.tokens_before, report.tokens_after, report.ratio)
print(report.basis, report.token_count_basis, report.method, report.recovery_handle)
```

`Cave` is a dataclass, so every field is a keyword argument: `api_key`, `base_url` and `agent` are required, and `default_workflow`, `retention`, `user`, `control_url` and `verify_on_init` have defaults. Provider bodies are plain dicts, passed positionally.

`cave.openai()`, `cave.anthropic()`, `cave.gemini()` and `cave.vertex()` return a `Provider` with `responses.create(...)` and `chat["completions"].create(...)`. `cave.bedrock(region=...)` describes the Bedrock surface and makes no request. [Provider calls](/docs/sdk/providers) covers all five.

## What a missing route prints

Running the second half of that program against a local proxy, which has no `/sdk/v1/compress`, gives the pass-through result:

```console
log 0 0 0.0
inferred unavailable None None
```

That is a pass-through: `output` is the payload you passed in, byte for byte. [Compression](/docs/sdk/compression) lists every trigger and the two fields that tell a pass-through from a real result.

`basis` reads `"inferred"` on every compression report this client returns. [Compression](/docs/sdk/compression) has the rest of the report and what the word means.

## Types

| Dataclass | Fields |
|---|---|
| `Cave` | `api_key`, `base_url`, `agent`, `default_workflow`, `retention`, `verify_on_init`, `control_url`, `user` |
| `CompressResult` | `output`, `content_type`, `tokens_before`, `tokens_after`, `ratio`, `basis`, `recovery_handle`, `method`, `lossless_to_model`, `token_count_basis` |
| `ContextPackItem`, `ContextPackOptions`, `ContextPackResult` | The budgeted context selector. See [Context packing](/docs/sdk/context) |
| `CaveTool`, `ToolSearchResult` | The deferred tool catalog. See [Deferred tools](/docs/sdk/tools) |
| `AssembleOptions`, `AssemblySlot`, `AssemblyResult` | Cache-optimal request assembly |

Field names match the TypeScript client one for one, in snake case. [API reference](/docs/sdk/reference) puts the two side by side.

## Limits

`Cave(...)` raises `TypeError` when `api_key`, `base_url` or `agent` is absent, and `ValueError` when `base_url` is not an absolute http or https URL without credentials, query or fragment. `compress()` passes the payload through rather than raising. A provider call raises `urllib.error.HTTPError` when the status is outside 2xx.
