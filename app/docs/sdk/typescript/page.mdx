`@caveman-ai/sdk` is a TypeScript client for a Caveman service: it makes provider calls through that service and sends payloads to its compression endpoint, then maps the reply into typed results. It is ESM only, has no runtime dependencies, and needs Node.js 22.13 or newer. This page documents published version 1.1.0.

Want tool results compressed inside a framework you already call, with no new code? Use [Middleware](/docs/sdk/middleware).

## Install

```bash
npm install @caveman-ai/sdk
```

## Configure

Every call goes to the address in `baseURL`. The `/sdk/v1/*` routes that `compress()`, `context`, `tools` and `runtimePolicy` use are served by a Caveman service; the local proxy on 127.0.0.1:8787 serves the provider routes and the middleware runtime, not those.

```bash
export CAVE_BASE_URL="https://your-caveman-service.example"
export CAVE_API_KEY="your-service-key"
export OPENAI_API_KEY="your-provider-key"
```

`agent` is a label you choose. It travels as `x-cave-agent` so the service can group requests by which application made them.

## The smallest complete program

```js
import { Cave } from "@caveman-ai/sdk";

const cave = new Cave({
  apiKey: process.env.CAVE_API_KEY,
  baseURL: process.env.CAVE_BASE_URL,
  agent: "support-agent",
});

const answer = await cave.openai({ upstreamKey: process.env.OPENAI_API_KEY }).responses.create({
  model: "gpt-5.5",
  input: "Explain what a retry loop is in one sentence.",
});
console.log(JSON.stringify(answer));

const log = Array.from({ length: 400 }, (_, i) => `2026-09-16T10:00:00Z INFO worker=${i} health check passed`).join("\n");
const report = await cave.compress(log, { contentType: "log" });

console.log({
  contentType: report.contentType,
  tokensBefore: report.tokensBefore,
  tokensAfter: report.tokensAfter,
  ratio: report.ratio,
  basis: report.basis,
  tokenCountBasis: report.tokenCountBasis,
  method: report.method,
  recoveryHandle: report.recoveryHandle,
});
```

`cave.openai()`, `cave.anthropic()`, `cave.gemini()`, `cave.bedrock()` and `cave.vertex()` each return a client shaped like that provider's own. [Provider calls](/docs/sdk/providers) covers the five and streaming.

## What a missing route prints

Running the second half of that program against a local proxy, which has no `/sdk/v1/compress`, gives the pass-through result:

```console
{
  contentType: 'log',
  tokensBefore: 0,
  tokensAfter: 0,
  ratio: 0,
  basis: 'inferred',
  tokenCountBasis: 'unavailable',
  method: undefined,
  recoveryHandle: undefined
}
```

That is a pass-through: `output` is the payload you passed in, byte for byte. [Compression](/docs/sdk/compression) lists every trigger and the two fields that tell a pass-through from a real result.

`basis` reads `"inferred"` on every compression report this client returns. [Compression](/docs/sdk/compression) has the rest of the report and what the word means.

## Types

Every option and result is exported, so you can hold one without widening it.

| Type | What it carries |
|---|---|
| `CaveOptions` | `apiKey`, `baseURL`, `agent`, plus `defaultWorkflow`, `retention`, `verifyOnInit`, `user`, `timeoutMs`, `signal`, `controlURL` |
| `CompressOptions` | `contentType`, a hint for the detector: `json`, `toon`, `log`, `code`, `diff`, `search-result`, `text`, `toolschema` |
| `CompressResult` | `output`, `contentType`, `tokensBefore`, `tokensAfter`, `ratio`, `basis`, `tokenCountBasis`, and optional `recoveryHandle`, `method`, `losslessToModel` |
| `ContextPackItem`, `ContextPackOptions`, `ContextPackResult` | The budgeted context selector. See [Context packing](/docs/sdk/context) |
| `CaveTool`, `ToolSearchResult` | The deferred tool catalog. See [Deferred tools](/docs/sdk/tools) |
| `CaveRequestError` | `status`, `path`, `message`, from the artifact and checkpoint calls |

```ts
import { Cave, type CompressResult, type CaveOptions } from "@caveman-ai/sdk";

const options: CaveOptions = { apiKey: "…", baseURL: "https://your-caveman-service.example", agent: "support-agent", timeoutMs: 30_000 };
const report: CompressResult = await new Cave(options).compress("{}", { contentType: "json" });
```

`timeoutMs` defaults to 30 seconds and applies to every request the client makes. `signal` cancels them all.

## Limits

`new Cave(...)` throws when `apiKey`, `baseURL` or `agent` is missing, and when `baseURL` carries credentials, a query string or a fragment. `compress()` passes the payload through rather than throwing. A provider call throws an `Error` carrying the service's response body when the status is outside 2xx.
